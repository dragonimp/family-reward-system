# 手表 app 真实上架清单

本清单区分“仓库内已交付”和“必须由发布主体在平台后台或真机上完成”的事项。仓库不保存账号、证书、密码或伪造的审核截图。

## 仓库内已交付

- Android WebView 工程、包名和版本配置。
- 小天才、小米、华为三平台配置及审核说明。
- 线上 `/watch/manifest.json` 与 `/api/watch/app-info` 元数据实现。
- 儿童认证码绑定、积分查询、积分申请、最近申请状态功能。
- SVG Web 图标、Android Vector Launcher 图标、中文商店文案和权限说明。
- 发布签名环境变量接线；签名信息缺失时 release 构建会明确失败。

## 发布主体必须提供

### 平台账号与准入

| 平台 | 必需账号/资格 | 提交前人工确认 |
| --- | --- | --- |
| 小天才 | 对应开放平台或商务合作账号、应用发布权限 | 手表为定制 Android，不是 Android Wear；需取得开放机型、官方开发数据线、ADB 权限和测试环境 |
| 小米 | 小米开发者账号、实名/企业认证、目标手表应用发布权限 | 目标设备系统、CPU ABI、商店分类和儿童应用政策 |
| 华为 | 华为开发者联盟账号、实名/企业认证、AppGallery Connect 项目 | 目标设备采用 Android/Wear OS 还是 HarmonyOS；HarmonyOS 原生包需另立工程，不能用本 Android 壳替代 |

平台规则会变化，最终字段、资质和素材规格以提交当日平台后台显示为准。

### 签名与构建

发布负责人在本地或 CI 注入以下变量，禁止提交真实值：

```text
HAPPYLIFE_WATCH_KEYSTORE=/absolute/path/release.keystore
HAPPYLIFE_WATCH_KEY_ALIAS=...
HAPPYLIFE_WATCH_KEYSTORE_PASSWORD=...
HAPPYLIFE_WATCH_KEY_PASSWORD=...
```

随后使用受控版本的 JDK、Android SDK 35 和 Gradle 运行 `:app:assembleRelease` 或平台要求的 bundle 任务。首次正式发布后必须备份 keystore；后续版本沿用同一签名。向平台上传前记录 APK/AAB 的 SHA-256、版本号、构建时间和签名证书指纹。

### 真机验收与截图边界

每个平台至少选择一款实际目标手表，覆盖仓库声明的屏幕规格。截图必须来自目标平台允许的真机截屏或官方模拟器，不得把浏览器桌面截图冒充真机素材。

小天才首版兼容边界为 Android 7.1.1/8.1.0、320x360、ARMv7 32 位开放机型，首轮建议 Z8 或 Z9。D3 的 Android 4.4/API 19 低于当前 `minSdk=23`，不在首版范围。设备从电商或线下渠道购买；开发数据线、ADB 权限和测试环境需联系小天才获取。AOSP Android 8.1 预检只能发现旧 WebView 兼容问题，不能替代定制系统真机结论。

- 设备绑定页：空白认证码，不包含可复用认证码。
- 积分首页：使用测试儿童与虚构家庭数据。
- 积分申请页：展示规则选择和申请提交，不展示家长管理入口。
- 最近申请页：至少包含待审核/已处理状态，不含真实儿童姓名、家庭名或设备标识。
- 断网提示与小屏滚动：作为测试证据保存，是否上传商店按平台要求决定。

至少验证 192×192、240×240、280×280、320×320、360×360 中与目标设备相符的尺寸；圆屏需检查安全区，方屏需检查边缘触控。截图分辨率、数量、横竖屏和圆角模板以提交后台即时要求为准。

### 平台后台资料

- 应用名称、简介、分类、图标、截图和审核备注。
- 隐私政策 URL、用户协议 URL、客服邮箱/网站、著作权与主体证明。
- 儿童/家庭类应用的年龄分级、数据安全和监护人同意问卷。
- 权限声明包含网络、网络状态和按需麦克风；麦克风仅用于用户主动语音输入且不保存原始录音。若平台包扫描结果不同，停止提交并排查。
- 测试账号或认证码仅通过平台安全字段提供，且审核结束后立即失效。

## 完成判定

仓库交付完成不等于三平台已经上架。只有取得平台受理单/版本号并保存以下证据后，才能把“真实上架”标记完成：签名产物哈希、目标设备与系统版本、真机用例结果、合规问卷回执、截图清单、平台审核状态。
