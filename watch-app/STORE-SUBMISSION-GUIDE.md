# 家加分手表端上架手册

更新时间：2026-08-20

本文用于把 `watch-app/` 当前交付物下发给发布负责人，按小天才、小米、华为三类手表分别执行上架。平台后台字段和审核规则会变化，最终以提交当天平台后台与官方文档为准。

## 2. 通用发布前准备

### 2.1 账号与主体

发布负责人必须准备：

- 平台开发者账号，并完成实名或企业认证。
- 软著、APP 电子版权认证证书或平台认可的版权/授权文件。
- APP 备案信息。若备案主体与开发者主体不一致，准备主体说明、营业执照和授权材料。
- 隐私政策 URL、用户协议 URL、客服邮箱或网站。
- 儿童/家庭类应用的数据安全、年龄分级、监护人同意说明。

### 2.2 签名与构建

真实签名证书不要提交到仓库。发布环境注入：

```bash
export HAPPYLIFE_WATCH_KEYSTORE=/absolute/path/release.keystore
export HAPPYLIFE_WATCH_KEY_ALIAS=...
export HAPPYLIFE_WATCH_KEYSTORE_PASSWORD=...
export HAPPYLIFE_WATCH_KEY_PASSWORD=...
```

打包：

```bash
cd watch-app/android
./gradlew :app:assembleRelease
```

提交前记录：

- APK/AAB 文件路径。
- SHA-256。
- versionName/versionCode。
- 签名证书 SHA-256 指纹。
- 构建时间、Git commit、构建机 JDK/Android SDK/Gradle 版本。

### 2.3 真机验收

每个平台至少用一台目标真机验收。最低用例：

1. 首次打开进入认证码绑定页。
2. 空认证码、错误认证码、过期认证码均有明确错误。
3. 家长 Web 端生成儿童认证码后，手表输入认证码绑定成功。
4. 绑定后重启应用仍保持登录态。
5. 积分首页无滚动条，姓名、积分圆环、现金/物品指标居中展示。
6. 积分可显示 `9999.9`。
7. 积分申请页可选择规则并提交。
8. 最近申请页显示待审核/已处理状态。
9. 手表端解绑必须输入家长生成的设备解绑码。
10. 断网或服务异常时展示可理解错误，不崩溃。

覆盖屏幕尺寸：

- 方屏：192x192、240x240、280x280、320x320、360x360 中至少覆盖目标型号。
- 圆屏：额外检查安全区，文字和按钮不得贴边或被裁切。
- 长屏/竖屏：确认无页面级滚动条，输入法弹出后仍可提交认证码。

### 2.4 截图素材

截图必须来自真机或平台允许的模拟器，不能用桌面浏览器截图冒充真机。

建议准备 5 张，平台要求少于 5 张时再裁剪：

1. 认证码绑定页，使用空白输入框，不展示真实认证码。
2. 积分首页，使用测试儿童和虚构积分。
3. 积分申请页，展示规则选择。
4. 最近申请页，展示待审核/已处理状态。
5. 解绑码页或断网提示页，按平台审核偏好选择。

隐私要求：

- 不展示真实儿童姓名、圈子名、设备 token、认证码、手机号。
- 审核测试账号或认证码只填平台后台的安全字段，审核结束后立即作废。

## 3. 小米手表上架

### 3.1 适用包

当前 Android WebView 壳可作为小米手表 APK 提交基础。当前配置满足：

- 包名：`net.impx.happylife.watch`
- targetSdk：35，满足小米手表应用发布指南中 targetSdk 不低于 26 的要求。
- 权限：仅网络与网络状态。
- 无小米、MIUI、米家等渠道标识。

若后续引入 native so，需按小米手表发布指南核对 CPU 适配，优先准备 32 位包体。

### 3.2 后台步骤

1. 登录小米澎湃 OS 开发者平台。
2. 进入手表应用，创建手表应用。
3. 填写应用名称和包名。包名必须与 APK 内 `applicationId` 一致。
4. 上传 APK，等待平台解析包名、版本、targetSdk、权限和 CPU 信息。
5. 核对权限，确认只有网络相关权限。
6. 配置发布设置：分类建议选教育、亲子或生活工具，以后台实际可选项为准。
7. 填写展示信息：应用名、一句话简介、应用介绍、隐私政策 URL、测试账号/认证码、截图。
8. 填写备案信息。
9. 上传软著或 APP 电子版权认证证书。
10. 填写联系人。
11. 提交审核。

### 3.3 小米材料建议

| 后台字段 | 建议填写 |
| --- | --- |
| 应用名称 | 手表积分 |
| 完整展示名 | 家加分手表积分 |
| 一句话简介 | 孩子查询积分并提交申请 |
| 应用介绍 | 使用 `watch-app/store-listing/listing.zh-CN.md` 的“应用简介” |
| 分类 | 教育 / 亲子 / 生活工具，按后台可选项取最贴合项 |
| 测试账号 | 提供家长测试账号和一次性儿童认证码，审核后作废 |
| 权限说明 | 网络访问用于打开手表端页面并提交积分申请；网络状态用于断网提示 |
| 截图 | 准备 3-5 张 PNG，优先按后台即时规格导出 |

### 3.4 小米高风险驳回点

- 应用名称、图标、软著、备案名称不一致。
- 一句话简介使用极限词、营销词或无关关键词。
- 截图模糊、拉伸、重复，或不是实际手表功能。
- 包体权限超出网络访问和网络状态。
- 需要登录但未提供有效测试账号或认证码。
- 儿童类应用出现诱导付费、广告、外链下载或不适合儿童内容。

## 4. 华为手表上架

### 4.1 先确认设备系统

华为手表提交前必须先确认目标设备类型：

- Android/Wear OS 兼容目标：可以用当前 Android WebView 壳作为基础，再按华为应用市场要求上传 APK。
- HarmonyOS 原生目标：需要单独建立 HarmonyOS/ArkTS 工程和 HAP/APP 包，不能用当前 Android WebView 壳直接替代。
- HarmonyOS 5/6 及更高版本：重点确认目标手表是否支持第三方应用分发、是否需要 HarmonyOS 原生适配。

### 4.2 后台步骤

1. 注册华为开发者账号并完成实名认证。
2. 进入 AppGallery Connect，创建项目和应用。
3. 填写应用包名、应用名称、分类和语言。
4. 上传应用包。Android 目标上传 APK/AAB；HarmonyOS 原生目标上传平台要求的 HarmonyOS 包。
5. 填写基础信息：应用名称、简介、图标、截图、分类。
6. 填写分发信息：分发国家/地区、付费情况、隐私声明链接。
7. 上传版权/资质文件。
8. 配置测试账号或审核说明，提供一次性儿童认证码。
9. 提交上架审核。

### 4.3 华为材料建议

| 后台字段 | 建议填写 |
| --- | --- |
| 应用名称 | 家加分手表积分或手表积分，需与软著/备案一致 |
| 类型 | 应用，非游戏 |
| 分类 | 教育 / 亲子 / 实用工具，以后台实际可选项为准 |
| 设备 | 选择目标手表/穿戴设备；如果后台没有目标设备入口，先提工单确认准入 |
| 隐私链接 | 必须可公网访问，HTTPS 优先 |
| 审核说明 | 手表端为孩子端，家长 Web 端生成认证码，手表只查询积分和提交申请 |
| 测试材料 | 家长测试账号、儿童认证码、目标设备型号、测试步骤 |

### 4.4 华为高风险驳回点

- 目标设备系统与包类型不匹配。
- HarmonyOS 手表要求原生包，但提交 Android 壳。
- 隐私政策、用户协议、权限说明缺失。
- 未说明儿童账号绑定流程，审核人员无法登录。
- 截图不是目标设备实际效果。

## 5. 小天才手表上架

### 5.1 准入判断

小天才公开文档说明手表是 Android 系统，不是 Android Wear，开发思路接近手机应用，但发布前仍需确认开放平台或商务合作准入。当前 Android WebView 壳可以作为技术基础，但真实上架通常需要先拿到：

- 小天才开放平台或商务合作账号。
- 应用发布权限。
- 目标机型和系统版本范围。
- 平台签名、测试和审核要求。
- 是否要求接入小天才账号授权或应用服务号。

如果平台要求小天才账号授权或应用服务号，需要评估是否接入；当前产品采用“家长 Web 端生成儿童认证码、手表端输入认证码绑定设备”的独立绑定模型。

### 5.2 后台/商务步骤

1. 联系小天才开放平台或商务接口，确认第三方应用上架入口和目标机型。
2. 提供应用基本信息、包名、功能说明、隐私政策和儿童数据说明。
3. 确认是否必须接入小天才账号授权、应用服务号或平台 SDK。
4. 按平台要求生成签名 APK。
5. 提交 APK、截图、审核账号/认证码、真机测试说明。
6. 根据平台反馈处理适配、SDK 或服务号要求。
7. 取得受理单、审核状态和最终版本号。

### 5.3 小天才材料建议

| 字段 | 建议填写 |
| --- | --- |
| 应用名称 | 家加分手表积分 / 手表积分 |
| 包名 | `net.impx.happylife.watch` |
| 功能说明 | 孩子查询积分、提交积分申请、查看申请状态 |
| 账号说明 | 无手表账号密码；输入家长端生成的一次性儿童认证码绑定设备 |
| 权限说明 | 网络访问、网络状态；主动语音输入时使用麦克风，不保存原始录音 |
| 目标机型 | 由平台确认，优先选择支持第三方应用和 WebView 的 4G 手表 |
| 特别说明 | 不含广告、付费、定位、通讯录、相机、短信和通话能力；麦克风仅用于主动语音输入 |

### 5.4 小天才高风险驳回点

- 未取得平台准入或目标机型不支持第三方应用。
- 平台要求账号授权/服务号但当前包未接入。
- WebView 页面在小圆屏/低分辨率设备上裁切。
- 手表输入法无法正常输入认证码。
- 审核认证码过期，审核人员无法进入绑定后页面。

## 6. 提交给平台的统一审核备注

可复制以下内容：

```text
家加分手表积分是家加分的孩子端手表应用。孩子首次使用时，需要家长在 Web 端家庭管理页面为该孩子生成一次性儿童认证码，孩子在手表端输入认证码完成设备绑定。绑定后手表端保存设备 token，仅允许孩子查看自己的积分、提交积分申请、查看最近申请状态，以及在输入家长生成的设备解绑码后解绑当前设备。

家长管理功能仅在 Web 端提供，包括圈子管理、家庭管理、积分规则、申请审核、设备查看和家长直接解绑。手表端不提供家长管理入口，不申请定位、通讯录、相机、短信、通话记录等权限。麦克风仅在孩子主动点击语音输入时申请，用于把申请事项转换为文字；服务端不保存原始录音，拒绝权限后仍可使用键盘输入。

审核测试请使用后台提供的测试家长账号登录 Web 端生成儿童认证码，或使用后台安全字段中提供的一次性儿童认证码。该认证码仅用于本次审核，审核结束后会立即作废。
```

## 7. 上架完成证据归档

每个平台归档一份目录：

```text
watch-release-evidence/
  xiaomi/
  huawei/
  xiaotiancai/
```

每个平台至少保存：

- 提交包 SHA-256。
- 签名证书 SHA-256 指纹。
- 平台应用 ID、版本号、提交时间。
- 目标设备型号和系统版本。
- 真机用例结果。
- 截图清单。
- 隐私合规/数据安全问卷回执。
- 审核受理单、审核通过截图或驳回意见。

没有这些证据，不应把“真实上架”标记为完成。
