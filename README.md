# 家庭奖励管理系统

## 项目简介
记录和激励孩子们的良好行为，通过积分和现金奖励系统培养孩子的习惯养成。

## 技术栈
- **后端**: Python (HTTP Server, 零依赖)
- **前端**: React + TypeScript + Vite
- **数据库**: SQLite (开发) / PostgreSQL (生产)

## 运行方式
```bash
cd server && python3 app.py
```

## 访问地址
- 本地: http://localhost:5102
- 域名: happylife.impx.net

## 功能模块
- 📊 仪表盘 - 总览所有孩子积分、排行榜
- 👨‍👩‍👧‍👦 孩子管理 - 管理孩子信息和账户
- 🎯 积分操作 - 添加/扣除积分、现金、物品
- 📋 交易记录 - 查看所有历史交易
- 📜 规则管理 - 积分规则和红线规则
- 📈 统计报表 - 详细统计数据
