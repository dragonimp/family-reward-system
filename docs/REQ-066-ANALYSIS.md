# family-reward-REQ-066 方形手表表盘需求分析

## 事项与结论

- Orbit 任务：`gpt_29ffce9eeb6e4b74bbffcc3b9ef81385`
- 需求：`family-reward-REQ-066`（`6eba3ec2-913d-4a3a-b30b-8cf77d1cc805`）
- 分析任务：`family-reward-TASK-239`（`6826f43f-23c2-4088-bf6b-1e5c0586a250`）
- 类型：变更（手表端表盘形状与多终端适配）
- 功能点：`245414ae-7163-46af-82bb-1bb73cf9a63b`

REQ-066 要求将手表端应用表盘设为方形，并兼顾小天才、华为和小米系列手表。仓库中的 [REQ-063 分析](./REQ-063-ANALYSIS.md)已经针对相同目标、相同终端范围给出完整规格；REQ-066 没有提供会改变设计或验收范围的新约束，应作为同一实施项去重管理，而不是再建设第二套品牌分叉页面。

实施前 `GET /watch` 的 `.watch-shell` 虽为等宽高容器，但 `.watch-face` 和 `.watch-face:before` 仍使用 `border-radius:50%`，实际显示为圆形。因此 `TASK-239` 可凭本文及对应提交关闭，不能以分析完成代替需求实现。如果项目管理侧确认 REQ-063 是主需求，可将 REQ-066 标记为重复并关联至 REQ-063；否则应复用下述规格进入一次实施。

## 实施进展（2026-09-05）

`/watch` 已按本规格完成统一方形实现：主表盘和内描边使用直角边界，主题继续由同一容器裁剪；表盘保留基础 `vw` 等宽高声明，并增加 `vmin` 回退和 `aspect-ratio` 能力增强；菜单按钮已从右侧负偏移移入右上安全区。REQ-066 静态回归、全量前端测试、lint、前后端构建和 240×240、320×360、390×390 浏览器视口检查均通过，三种视口横纵向溢出为 0。

尚未取得小天才、华为、小米三类目标真机记录，也未执行生产部署和线上复测；因此当前成果可作为代码实现完成证据，但不能替代 TC-066-04 至 TC-066-06 的真机验收或部署关闭证据。

## 统一产品口径

1. “方形”指应用表盘主容器、内描边和主题裁剪区域采用直角方形；积分环属于内容组件，可保留圆形。
2. 使用一套响应式页面适配三类终端，不通过 User-Agent、品牌或型号复制页面，也不仿制厂商商标和系统 UI。
3. 保留现有绑定、积分、规则、申请、好友、排行榜、表盘选择和 VIP 权益逻辑；本需求不变更 API、数据库、主题代码或付费模型。
4. 以可用视口最小边确定正方形尺寸，并同时保留旧 WebView 可理解的 `width/height` 回退；现代能力可用 `min()`、`clamp()`、`dvh` 和 `aspect-ratio` 增强。
5. 菜单按钮和所有交互内容必须位于方形安全区内，不再依赖圆形外框右侧负偏移；系统圆角、状态栏或表冠遮挡不能截断主要操作。

建议实现至少满足：

- `.watch-face` 与 `.watch-face:before` 不再使用 `border-radius:50%`；免费和 VIP 主题共用同一方形裁剪边界。
- `.watch-shell` 保持 1:1；Android 7.1.1/8.1.0 旧 WebView 在不支持新 CSS 时仍能获得确定的等宽高布局。
- `.screen`、表单、列表和菜单使用容器内可用空间，长儿童姓名、长规则名和大字体不会引起横向滚动。
- 右侧菜单按钮完整位于可点击安全区，最小目标尺寸不低于当前约 `34px` 的下限。
- 新增静态需求测试，证明方形规则、兼容回退和窄屏规则存在；静态测试不能替代目标设备视觉验收。

## 风险与依赖

- 仓库仅对小天才 Android WebView 路径记录了较明确的系统和分辨率；华为、小米仍需在实施验收前确定目标型号、系统、WebView/容器和可用安全区。厂商名称不能替代设备矩阵。
- 小天才 D3 为 240×240、Android 4.4，而当前应用 `minSdk=23`，不属于现有首版支持范围；240×240 可用于布局压力测试，但不能据此宣称 D3 真机兼容。
- 旧 WebView 对 `dvh`、`min()`、`clamp()` 和 `aspect-ratio` 支持不一致，必须保留现有基础 `calc(100vw - 52px)` 等回退，不能只依赖现代声明。
- 如果产品仍要求支持圆屏，必须另行给出圆屏识别、外观降级和验收设备；REQ-066 当前文字只支持“统一方形”的解释。
