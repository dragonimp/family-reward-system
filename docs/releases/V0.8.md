# 家加分 V0.8 版本记录

## 版本信息

- 产品版本：`V0.8`
- 冻结日期：2026-09-02
- 发布分支：`main`
- Git 标签：`v0.8`
- 版本定位：现有家庭积分能力的稳定基线，也是亲子双向成长能力升级前的保存点。

> 本文记录的是“家加分”整体产品版本。后端健康检查中的服务版本、手表 Android 安装包版本保持各自独立口径，不随本次产品基线标记调整。

## 已包含能力

### 家长 Web

- 统一登录、家长/孩子应用身份和受保护路由。
- 家庭圈子创建、邀请、加入、切换和成员管理。
- 孩子档案、家庭成员、全局积分账户和设备管理。
- 积分、现金、物品的正负调整以及交易查询、筛选和 CSV 导出。
- 公共规则、个人规则、红线规则和个人规则模板。
- 仪表盘、孩子积分统计、类别分布和排行榜。
- 家长手机端虚拟手表、系统配置、智能体助手和订阅管理。

### 儿童手表

- 一次性认证码绑定和一次性解绑码。
- 积分、现金、物品查询。
- 按规则提交积分申请并查看处理状态。
- 语音填写申请事项。
- 好友码、好友列表和好友积分榜。
- 多款表盘与家长端虚拟预览。
- 小米、华为、小天才三平台工程及上架材料准备。

### 服务与集成

- ASP.NET Core Minimal API 与 PostgreSQL 持久化。
- 家庭、孩子、账户、交易、规则、设备和申请的服务端权限隔离。
- MCP/JSON-RPC 工具目录及家庭积分业务工具。
- AgentFree 智能体工作台和公共反馈入口。

## 当前产品边界

- 产品主流程仍以“孩子积分账户、家长记账与审批”为中心。
- 尚未提供孩子记录家长闪光时刻、家长暖心积分和亲子双向成长账本。
- 尚未提供家长成长日历、孩子/家长成长周报与月报。
- 当前统计仍包含孩子和好友间的积分排行，尚未转为以个人成长趋势为主。
- 成长事实仍主要承载在交易描述与积分申请中，尚未建立独立成长事件模型。
- 方形手表表盘需求已有分析，但尚未完成统一实现和三类目标设备验证。
- 三平台工程与材料已经准备，真实商店上架仍依赖主体账号、证书、合规资料和目标真机。

## 后续演进方向

V0.8 之后的产品演进以“记录事实、互相看见、共同成长”为原则，优先推进：

1. 独立成长事件模型，将成长事实与积分交易分离。
2. 孩子记录家长闪光时刻，形成非评判式的暖心记录。
3. 孩子成长与家长成长并列展示的家庭账本。
4. 以个人变化为核心的周报、月报、成长日历和里程碑。
5. 弱化默认排名，完善隐私、可见范围和 AI 建议边界。
