## 服务器本机探针

在生产主机回环地址直接访问：

| 接口 | 状态 | 耗时 | 响应大小 |
| --- | --- | ---: | ---: |
| `/health` | HTTP 200 | 3.414 ms | 73 字节 |
| `/watch` | HTTP 200 | 0.811 ms | 35,836 字节 |

测试时服务状态为 `active`。服务器根分区已用 82%，可用约 15 GiB；内存可用约 987 MiB。该资源水位不影响本次低并发测试，但应继续保留磁盘和内存监控告警。

## 风险与结论

- 700 次公网请求均无失败，满足家庭奖励场景和平台审核期间的低并发访问需求。
- `/watch` P95 受公网 TLS、链路和静态页面传输影响，明显高于服务器回环耗时；后续可通过 CDN/缓存和压缩进一步优化。
- 本次只对无副作用接口做受控压测，未对绑定、积分申请等写接口制造生产数据。
- 该报告证明 2026-08-20 测试窗口内的可用性和响应表现，不等同于长期容量承诺；正式运营继续依赖监控、告警和故障恢复流程。
