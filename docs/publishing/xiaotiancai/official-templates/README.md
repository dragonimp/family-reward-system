## 使用规则

1. 正式真机执行前先向小天才确认本次指定机型、系统版本和是否有更新模板。
2. 测试用例表按家加分真实功能填写，不保留范例中的故事播放用例。
3. V1.7 check 表所有适用项均需填写测试结果；不适用项写明原因，不得留空冒充通过。
4. V1.3 性能表在小天才指定真机上采集；AOSP 模拟器结果只能写入备注，不能作为真机结论。
5. 官网页面与模板文字冲突时，优先采用当前官网审核规范中的较新或更严格要求，并在报告中记录来源和差异。
