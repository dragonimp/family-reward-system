## 首次提交服务器能力说明

家加分手表端主要通过 HTTPS 访问 `happylife.ai.impx.net`。首次提交时，如小天才要求服务端负载或性能报告，可按以下维度补充：

- 健康检查持续可用性。
- `/watch` 静态页面响应。
- `/api/watch/score`、`/api/watch/rules`、`/api/watch/requests`、`/api/watch/device-bind` 接口响应。
- 审核测试期间并发量预估：低并发家庭奖励场景。

正式服务器性能数据需要从生产监控或压测结果导出，本仓库不伪造监控截图。
