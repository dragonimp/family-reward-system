## 审核备注

```text
手表端仅面向孩子使用，不提供家庭组管理、规则配置、申请审核、账号注册、付费、广告或外链下载能力。

使用流程：
1. 家长在 Web 端注册/登录家加分账号。
2. 家长在孩子管理中创建儿童账号，并生成一次性儿童认证码。
3. 孩子在手表端输入认证码完成设备绑定。
4. 绑定后手表端只允许查询积分、提交积分申请、查看最近申请状态。
5. 如需解绑，家长可在 Web 端直接解绑设备，或生成设备解绑码，由孩子在手表端输入后解绑当前设备。

审核测试请使用平台安全字段提供的测试家长账号和一次性认证码；审核结束后认证码会作废。
```
