## 当前准出标准

| 类别 | 官网当前要求 | 家加分执行口径 |
| --- | --- | --- |
| 启动 | 冷启动首帧完成小于 1 秒；页面可交互小于 1.5 秒；超过 1.5 秒必须给出进度反馈 | 在平台指定真机用 ActivityTaskManager 日志和录屏时间线记录 |
| 页面切换 | 页面或功能切换加载超过 500 毫秒即不满足审核规范 | 绑定、首页、菜单、申请、最近申请、解绑逐项计时 |
| CPU | 前台小于 70%；普通应用后台息屏为 0%；必要后台任务不超过 8% | 家加分无必要后台任务，按 0% 验收 |
| 内存 | 峰值不超过 160 MB，均值不超过 60 MB | 记录完整主流程均值和峰值，检查内存泄漏 |
| 流畅度 | 卡顿率不超过 0.1%；V1.3 模板要求普通应用列表滑动不低于 58 FPS | 手工全功能组合操作并采集 Choreographer 日志 |
| 功耗 | 不得后台保活、频繁唤醒或联网；V1.7 要求连续使用 30 分钟耗电不超过 20% | 记录环境温度、起止电量、温升、高温告警和网络请求 |
| 流量 | V1.7 对纯浏览类 4G 连续使用 30 分钟要求不超过 5 MB | 绑定、查询、申请、状态刷新分项记录；不得盲目重试 |
| 稳定性 | 官网审核规范要求 Monkey 和自动化遍历各累计 18 小时，最小连续 8 小时，覆盖三层及以上页面，0 Crash/ANR/内存泄漏 | 小天才真机取得后执行；当前 AOSP 预检不得替代 |
| 安装空间 | 版本页面要求 APK 小于等于 30 MB、安装后小于等于 40 MB；V1.7 对 512 MB 设备给出 10/15 MB 更严格值 | 由平台指定机型内存规格后采用对应阈值；当前 APK 仅证明安装包大小 |
| 兼容性 | 不同型号、系统版本界面和功能均正常 | 至少覆盖平台指定的 2-3 台开放机型，记录型号、系统、固件、网络和原始截图 |
| 内容与合规 | 无儿童不宜及违法内容；账号、备注等用户生成内容需管控；权限和隐私须最小必要 | 验证孩子名、家庭备注、申请文本、语音转写及反馈路径的内容安全与删除能力 |

## 模板差异处理

官网当前页面链接的原件仍包含部分历史文字：测试流程举例使用 Z2/Z3/Z5，V1.3 性能模板对标 Z12，V1.7 check 表还列出早期平台和阈值，基础信息模板甚至保留旧邮箱。正式执行不自行猜测首发机型，邮件中应要求小天才确认当前指定开放机型；收件邮箱和版本格式以当前“版本提供”页面的 `developer@eebbk.com` 与 `〖版本验收〗xx应用` 为准。
