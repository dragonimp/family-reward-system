# 真正需要发布主体提供的材料

以下材料无法由仓库直接生成，必须由你或公司发布主体提供。其他文案、模板、测试清单和邮件正文已在本目录准备。

## 公司与主体材料

- 小天才开发者账号或商务合作准入。
- 发布主体公司名称，必须与营业执照、软著、协议和隐私政策一致。
- 营业执照扫描件。
- 法定代表人身份证正反面复印件。
- 联系人姓名、手机号、邮箱。
- 客服邮箱；如平台要求，提供客服电话或服务号。

## 权利与合规材料

- “家加分手表积分”或对应软件的软件著作权登记证书。
- 首次提交免责函，需法务确认并按平台要求盖章/签字。
- 隐私政策最终 HTTPS URL。
- 用户协议最终 HTTPS URL。
- 儿童个人信息处理、监护人同意、数据安全问卷的最终确认答案。

## 平台账号与密钥

- 小天才分配的 `appId`、`appSecret` 和权限范围，如需要接入小天才账号系统或开放接口。
- 测试环境和生产环境是否使用不同 `appId` / `appSecret` 的确认。
- 小天才审核沟通群或商务联系人信息。

## 构建与签名

- Android 发布 keystore 文件。
- `HAPPYLIFE_WATCH_KEYSTORE`
- `HAPPYLIFE_WATCH_KEY_ALIAS`
- `HAPPYLIFE_WATCH_KEYSTORE_PASSWORD`
- `HAPPYLIFE_WATCH_KEY_PASSWORD`
- 签名 APK 的 SHA-256、签名证书指纹、构建时间记录。

## 真机与素材

- 小天才目标机型和系统版本。
- 目标真机测试结果。
- 小天才真机或官方允许方式生成的截图。
- 148 x 148 PNG 应用图标。
- 320 x 360 PNG 应用介绍图 3-5 张。

## 审核测试

- 审核用家长测试账号。
- 审核用一次性儿童认证码。
- 审核结束后作废测试认证码和撤销测试设备绑定的确认。
