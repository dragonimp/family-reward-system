# 小天才审核与客服使用说明

## 角色说明

- 家长端：Web 端，负责账号注册、孩子管理、规则配置、申请审核、设备管理。
- 手表端：小天才手表 App，负责孩子绑定设备、查看积分、提交积分申请、查看最近申请状态。

## 审核测试流程

1. 使用系统从用户中心凭证管理安全引用并已核验的测试家长账号登录 Web 端。
2. 进入“孩子管理”，创建或选择测试儿童。
3. 点击“生成认证码”，得到一次性儿童认证码。
4. 打开小天才手表端 App。
5. 在认证码绑定页输入该认证码。
6. 绑定成功后进入积分首页。
7. 查看积分、现金、物品数量。
8. 进入积分申请页，选择一条规则并提交申请。
9. 进入最近申请页，确认申请状态展示。
10. 如需测试解绑，家长端选择该手表设备生成解绑码，手表端输入解绑码后解绑当前设备。

## 异常场景

| 场景 | 预期结果 |
| --- | --- |
| 空认证码 | 提示请输入儿童认证码 |
| 错误认证码 | 提示认证码无效或已过期 |
| 过期认证码 | 提示认证码无效或已过期 |
| 未绑定设备访问积分接口 | 返回 `watch_device_required` |
| 已解绑设备继续访问 | 返回 `watch_device_invalid` |
| 错误解绑码 | 提示解绑认证码无效或已过期 |

## 权限说明

手表端只需要网络访问和网络状态检测，用于加载家加分手表端页面、查询积分、提交积分申请和同步申请状态。

## 客服说明

如果审核或客服无法进入绑定后页面，应先确认：

- 测试家长账号是否有效。
- 儿童认证码是否仍在有效期内且未被使用。
- 手表网络是否能访问 `https://happylife.ai.impx.net/watch`。
- 该测试儿童是否已经绑定其他有效手表设备；当前实现同一儿童仅允许一个有效手表绑定。

审核完成后，应在家长端撤销测试设备绑定，并作废用于审核的一次性认证码。
