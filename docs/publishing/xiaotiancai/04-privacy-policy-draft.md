# 家加分手表积分隐私政策草案

版本：1.0

生效日期：待发布主体确认

本草案用于小天才提审前法律审核。正式发布前必须由发布主体确认公司名称、联系方式、隐私政策 URL 和适用条款。

## 一、我们收集的信息

家加分手表积分是家加分的孩子端手表应用。为了完成设备绑定、积分查询和积分申请，我们可能处理以下信息：

- 家长在 Web 端创建的儿童账号信息，例如昵称、积分、现金和物品奖励数量。
- 家长生成的一次性儿童认证码，用于手表端完成设备绑定。
- 手表设备绑定 token、绑定时间、最后访问时间和解绑状态。
- 孩子在手表端提交的积分申请记录，包括规则、说明、状态和提交时间。
- 必要的网络请求信息，用于服务安全、错误排查和接口访问控制。

## 二、我们如何使用信息

上述信息仅用于：

- 识别手表设备与儿童账号的绑定关系。
- 展示孩子自己的积分、现金和物品奖励信息。
- 提交并展示积分申请状态。
- 支持家长在 Web 端管理设备绑定和解绑。
- 保障服务稳定性、安全性和合规审计。

## 三、儿童个人信息保护

家加分面向家庭奖励管理场景。孩子端手表应用不提供账号注册、社交、广告、付费、公开发布或外链下载能力。儿童账号由家长在 Web 端创建和管理，手表端通过家长生成的一次性认证码绑定设备。

家长可以在 Web 端查看、修改和删除孩子信息，管理手表设备绑定，并撤销不再使用的设备。

## 四、信息共享

未经家长同意，我们不会向无关第三方出售、出租或披露儿童个人信息。为完成小天才平台分发和账号能力接入，若接入小天才官方 SDK 或开放接口，我们仅按实现所必需的范围调用相关能力。

## 五、信息存储与安全

我们使用 HTTPS 传输数据，并对设备绑定 token 和认证码进行访问控制。认证码为一次性使用，过期或使用后失效。解绑码同样为一次性使用，成功解绑后立即失效。

## 六、账号注销与数据删除

家长可以联系发布主体或在产品提供的功能范围内申请删除账号及相关儿童数据。账号注销或数据删除后，我们将按法律法规和安全要求删除或匿名化处理相关数据。
