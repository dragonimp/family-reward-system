# 家加分手表积分隐私政策

版本：1.0
发布及生效日期：2026年8月20日
运营者：厦门图灵软件有限公司
正式页面：<https://happylife.ai.impx.net/legal/privacy.html>

本应用面向未成年人使用。儿童账号由监护人在家加分 Web 端创建和管理，手表端仅通过监护人生成的一次性认证码完成设备绑定。

## 一、我们处理的信息

- 监护人创建的儿童昵称、积分、现金和物品奖励数量。
- 一次性儿童认证码、设备绑定令牌、绑定及解绑状态、最后访问时间。
- 孩子提交的积分申请，包括所选规则、识别或输入的文字、处理状态和时间。
- 必要的网络日志，例如访问时间、网络地址、设备型号、系统和应用版本，用于安全审计与故障排查。

## 二、设备权限

- 网络访问和网络状态：加载手表页面、查询积分、提交申请和展示断网提示。
- 麦克风：仅在孩子主动点击语音输入按钮时申请，用于将申请事项转换为文字。家加分服务端不保存原始录音，只接收识别后的文字；不使用语音功能时可以拒绝该权限并改用键盘输入。

本应用不申请定位、通讯录、相机、短信、通话记录或后台常驻权限。

## 三、处理目的

上述信息仅用于设备与儿童账号绑定、展示孩子自己的奖励资产、提交和跟踪积分申请、由监护人管理设备，以及保障系统安全与稳定运行。

## 四、儿童个人信息保护与监护人控制

监护人通过家加分 Web 端创建儿童账号并生成绑定码，视为在了解本政策后授权孩子使用手表端。监护人可以查看、修改或删除孩子信息，撤销设备绑定，并联系我们办理账号注销或数据删除。

## 五、共享、委托处理与转让

我们不出售儿童个人信息。为完成登录、应用分发、基础设施运行或用户主动使用的语音识别，相关服务提供方可能在必要范围内处理信息。我们会要求其遵守适用的隐私和安全义务。发生合并、分立或资产转让时，我们会依法告知并要求承接方继续履行本政策。

## 六、保存与安全

信息存储于中国境内的受控服务器，并通过 HTTPS、访问控制、一次性认证码、设备令牌和审计措施进行保护。我们仅在实现服务、解决争议及履行法定义务所需期限内保存信息，超过期限后删除或匿名化处理。

## 七、您的权利

监护人可以通过家加分 Web 端行使查询、更正、删除、撤回设备授权等权利，也可以通过下方联系方式提出复制、注销或投诉请求。我们会核验监护人身份后处理，避免儿童信息被未授权访问。

## 八、政策更新

功能、权限或法律规则发生实质变化时，我们会更新本政策并以合理方式提示。涉及儿童信息处理目的、方式或范围的重要变化，将依法重新取得监护人同意。
