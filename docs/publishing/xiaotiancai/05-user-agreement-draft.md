监护人为孩子生成认证码并允许其绑定手表设备前，请阅读本协议和《家加分手表积分隐私政策》。

## 一、服务内容

家加分手表积分为家加分的孩子端应用，提供儿童认证码设备绑定、积分及家庭奖励资产查询、积分申请、申请状态查看和设备解绑。家长账号注册、家庭成员、圈子、奖励规则和申请审核在 Web 端完成。

## 二、账号和设备绑定

1. 家长应使用本人账号创建和管理儿童账号，并确认有权处理相关儿童信息。
2. 儿童认证码和解绑码均为一次性凭证，不得公开传播或提供给无关人员。
3. 发现设备丢失、异常绑定或信息泄露时，家长应立即在 Web 端撤销设备并联系我们。

## 三、家庭奖励规则

应用中的积分、现金和物品记录用于家庭内部奖励管理，不是平台发行的货币、储值账户或金融产品。具体奖励是否兑现、兑现方式和家庭规则由监护人决定。

## 四、用户行为规范

用户不得利用本服务实施违法违规、侵害他人权益、绕过权限、破坏系统、批量抓取、传播恶意内容或干扰平台审核的行为。监护人应结合儿童年龄和家庭情况合理设置奖励内容，并履行监护责任。

## 五、隐私与数据安全

我们按照《家加分手表积分隐私政策》处理相关信息。语音输入仅在用户主动操作时使用，用户可以拒绝麦克风权限并使用键盘输入。
