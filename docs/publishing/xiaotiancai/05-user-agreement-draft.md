# 家加分手表积分用户协议草案

版本：1.0

生效日期：由项目生成正式版本时写入，发布前由主体授权人确认

本草案用于小天才提审前法律审核。正式发布前必须由发布主体确认公司名称、联系方式和最终条款。

## 一、服务内容

家加分手表积分是家加分的孩子端手表应用。孩子可在手表端查看积分、提交积分申请和查看申请状态。家长在 Web 端负责账号注册、儿童账号创建、家庭组管理、奖励规则、申请审核和设备绑定管理。

## 二、账号与设备绑定

手表端不直接注册家长账号。家长需要先在 Web 端注册/登录，并为孩子生成一次性儿童认证码。孩子在手表端输入认证码后，手表设备与对应儿童账号绑定。

请妥善保管认证码。认证码仅用于绑定审核或家庭内部使用，不应公开传播。

## 三、用户行为规范

用户不得利用本服务进行违法违规、侵害他人权益、破坏系统安全或干扰正常服务的行为。家长应确保孩子在合理监护下使用本应用。

## 四、服务变更和中止

我们可能因产品升级、系统维护、平台规则变化或不可抗力调整服务内容。对于影响用户使用的重要变更，我们将通过合理方式提示用户。

## 五、责任限制

本应用用于家庭奖励管理和亲子激励，不构成教育、医疗、心理或财务建议。家长应根据家庭情况合理设置规则和奖励内容。

## 六、知识产权

家加分手表积分相关软件、界面、文案和技术实现的知识产权归发布主体或合法权利人所有。未经许可，用户不得复制、修改、反向工程或用于未授权用途。
