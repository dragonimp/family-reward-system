# 小米需要发布主体提供的材料

## 平台账号

- 小米澎湃 OS 开发者平台账号。
- 账号实名认证或企业认证。
- 手表应用发布权限。
- 平台联系人姓名、职务、手机号、邮箱。
- 上架过程中短信验证码的人工输入。

## 权利和资质

- 软件著作权登记证书或 APP 电子版权认证证书。
- 如版权主体与开发者账号主体不一致，提供授权证明。
- APP 备案信息。
- 备案主体与开发者账号主体不一致时，提供备案主体名称、统一社会信用代码、营业执照附件和备案说明。
- 特殊行业资质确认；当前家加分不应按金融、医疗、政务、彩票等特殊行业申报。

## 素材和包体

- 签名 APK。
- 512 x 512 PNG 图标，四角透明，中间圆形，与 APK 桌面图标一致。
- 1080 x 1080 PNG 截图，默认准备 4 张。
- 隐私政策 URL。
- 审核测试家长账号。
- 一次性儿童认证码。
- 真机型号、系统版本和测试结论。
