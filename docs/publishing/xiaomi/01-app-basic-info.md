# 小米应用基础资料

## 基础字段

| 字段 | 建议填写 |
| --- | --- |
| 应用创建名称 | 家加分 |
| 后台展示名称 | 家加分 |
| 软著对应名称 | 需与软著/备案名称一致，若软著为“家加分手表积分”则后台名称应同步 |
| 包名 | `net.impx.happylife.watch` |
| Version Name | `1.0.0` |
| Version Code | `100` |
| 分类 | 生活服务 / 实用工具 / 亲子家庭类，最终以后台可选分类为准 |
| 上架时间 | 审核通过后立即上架 |
| 一句话简介 | 孩子积分奖励助手 |
| 应用介绍 | 家加分是家庭奖励管理工具。孩子可在手表端查看积分、提交奖励申请并查看申请状态，家长在 Web 端管理孩子、规则、审核和设备绑定。 |
| 隐私政策 URL | 从项目管理平台账号或应用上架材料读取 |
| 测试账号 | 从项目管理平台账号读取审核测试家长账号和一次性儿童认证码 |

## 更新日志

```text
首版上线。支持手表端认证码绑定、积分查询、积分申请、最近申请状态和设备解绑码。
```

## 素材规格

| 素材 | 小米要求 | 当前准备策略 |
| --- | --- | --- |
| 应用图标 | PNG，512 x 512 px；中间圆形、四角透明；与安装后桌面图标一致 | 需导出最终 PNG |
| 应用截图 | PNG，1080 x 1080 px；单张不超过 5 MB；官方文档对数量有 3-4 与 3-5 的差异 | 默认准备 4 张，最终以后台校验为准 |
| APK | `.apk`，包名与创建应用一致 | 需签名后上传 |
| 软著/版权 | 计算机软件著作权登记证书或 APP 电子版权认证证书 | 需发布主体提供 |
| 备案信息 | APP 备案信息；主体不一致需提供主体名称、统一社会信用代码、营业执照附件和备案说明 | 需发布主体提供 |
