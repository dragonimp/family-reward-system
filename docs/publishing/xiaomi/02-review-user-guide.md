# 小米审核使用说明

## 审核流程

1. 使用审核专用家长账号登录 Linko Moment 手机端或 Web 端。
2. 在“孩子管理”中选择测试儿童并生成一次性儿童认证码。
3. 在小米手表端打开“Linko Moment”。
4. 输入儿童认证码完成设备绑定。
5. 查看积分首页。
6. 提交一条积分申请。
7. 查看最近申请状态。
8. 如需测试解绑，家长在 Web 端生成设备解绑码，手表端输入后解绑当前设备。

## 审核备注

```text
手表端为孩子端应用，不提供家长管理、支付、广告、社交、外链下载或第三方应用市场跳转。
家长在手机端或 Web 端管理孩子，并生成一次性认证码；孩子在手表端输入认证码后绑定设备。
绑定后手表端只允许孩子查询积分、提交积分申请和查看申请状态。
```

审核用账号、验证码及设备绑定码须在实际提交时通过小米后台的受控审核字段提供，并先验证有效期；本文档不保存账号凭据。当前尚未完成手表真机和审核账号验收，不能将本说明视为已通过审核流程。

## 小米高风险点

- 应用名称、软著名称、备案名称和安装后名称不一致。
- 应用名称超过小米手表展示限制，或包含副标题/特殊符号/小米渠道标识。
- 图标与 APK 解析图标不一致。
- 截图不是手表实际功能，或重复、拉伸、模糊。
- 测试账号/认证码失效导致审核无法进入绑定后页面。
- 隐私政策链接不可访问或超过后台限制。
- 包名含有 `.xiaomi`、`.mijia`、`.miui` 等未授权渠道标识。
