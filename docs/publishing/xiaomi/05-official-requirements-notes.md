# 小米官方要求核对笔记

资料整理日期：2026-08-13

## 发布操作指南

官方页面：https://dev.mi.com/xiaomihyperos/documentation/detail?pId=2058

核对项：

- 创建手表应用时需要应用名称和应用包名。
- 创建时应用名称不超过 30 个字符。
- 包名至少两段，以 `.` 分割；每段以字母开头，可包含字母、数字和下划线。
- 上传 APK 后平台解析包名、版本、targetSdk、权限和 CPU 信息。
- APK 包名必须与创建应用包名一致。
- CPU 适配需上传 32 位包体。
- targetSdk 需不低于 26。
- 发布设置需要选择应用分类和上架时间。
- 展示信息需要应用名称、图标、版本名称、一句话简介、应用介绍、隐私政策 URL、测试账号和截图。
- 隐私政策 URL 以 http 或 https 开头，后台限制 150 个字符。
- 联系人信息需要姓名、手机号、验证码和邮箱。
- 提交后官方文档说明审核通常 1-3 个工作日。

## 上架要求

官方页面：https://dev.mi.com/xiaomihyperos/documentation/detail?pId=2059

核对项：

- 包名不得随意添加 `.xiaomi`、`.mijia`、`.miui` 等小米渠道标识。
- 应用名称不得添加副标题，不得超过 20 个英文字符，且应与软著或商标保持一致。
- 手机端与手表端关联使用时，两端应用名称主体需保持一致。
- 图标 PNG 512 x 512 px，中间圆形、四角透明，需与安装后桌面图标一致。
- 一句话简介不得超过 34 个字符，避免极限词、疑问反问句式、无关关键词和其他应用市场引导。
- 应用介绍和更新日志长度应在 20-500 英文字符之间，不得包含第三方应用市场名称或无关信息。
- 截图 3-5 张，PNG，1080 x 1080 px，单张不超过 5 MB，不得重复、拉伸、模糊或与实际功能不符。
- 需要按隐私合规标准自查。

## 文档差异

发布操作指南中截图数量写“至少 3 张、至多 4 张”，上架要求写“3-5 张”。当前资料包默认准备 4 张，最终以提交后台即时校验为准。
