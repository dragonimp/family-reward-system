# 华为审核使用说明

## 审核流程

1. 使用项目管理平台账号配置的测试家长账号登录家加分 Web 端。
2. 进入“孩子管理”，为测试儿童生成一次性儿童认证码。
3. 在华为目标手表端安装并打开“家加分”。
4. 输入儿童认证码完成绑定。
5. 查看积分首页。
6. 提交积分申请。
7. 查看最近申请状态。
8. 使用家长端生成的设备解绑码测试解绑当前设备。

## 审核备注

```text
本应用为家庭奖励管理的孩子端手表应用。手表端不提供账号注册、家长管理、支付、广告、社交、外链下载或第三方应用市场跳转。
家长在 Web 端创建儿童账号并生成一次性认证码；孩子在手表端输入认证码后绑定设备。
绑定后手表端只允许孩子查询积分、提交积分申请和查看最近申请状态。
```

## 华为高风险点

- 未确认目标手表是否支持 Android APK，误把 Android 壳提交到 HarmonyOS 原生要求场景。
- 软件包签名、包名、版本号与 AppGallery Connect 应用信息不一致。
- 隐私政策、用户协议、权限说明和实际采集数据不一致。
- 年龄分级、儿童个人信息和监护人同意说明缺失。
- 软著/版权主体、备案主体和开发者主体不一致但未提供说明或授权。
- 审核测试账号或认证码失效。
