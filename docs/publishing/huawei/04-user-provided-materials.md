# 华为需要发布主体提供的材料

## 平台账号

- 华为开发者联盟账号。
- 企业实名认证。
- AppGallery Connect 项目和应用。
- 如要自动化发布，提供 Service Account 或 API Client 配置，并在项目管理中保存密钥引用。
- 联系人姓名、手机号、邮箱。

## 技术确认

- 目标华为手表型号和系统版本。
- 明确目标设备是否支持 Android APK 路径。
- 如果目标是 HarmonyOS 原生手表或 HarmonyOS NEXT，需另立 HarmonyOS 工程，当前 Android WebView 壳不能直接提交。

## 权利和合规

- 软件著作权登记证书或电子版权证书。
- 如主体不一致，提供授权证明。
- APP 备案/核准信息。
- 隐私政策 URL。
- 用户协议 URL。
- 年龄分级和儿童个人信息处理说明。
- 数据安全/隐私标签问卷答案。

## 素材和包体

- 签名 APK，或 HarmonyOS 原生包体。
- 应用图标。
- 应用截图。
- 应用介绍。
- 更新说明。
- 审核测试家长账号。
- 一次性儿童认证码。
- 真机测试报告。
