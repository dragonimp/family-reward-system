# Linko Moment Android 手机端上架准备

| 字段 | 值 |

本材料只适用于 Android 手机端。Android 儿童手表使用独立包名和材料。新包名与此前 `net.impx.happylife.parent.android` 不同，商店和系统会将其视作另一个应用；原包不能直接覆盖升级，账号与服务端数据可通过同一用户中心重新登录访问。

## 商店文案草稿

**短介绍：** 与家人一起记录成长，管理奖励与家庭事务。

**完整介绍：** Linko Moment 让家长在手机上管理家庭成员、孩子积分和零用钱。可以添加孩子，查看家庭规则，记录积分、零用钱及物品的奖励或扣除，处理孩子提交的申请，并查看交易记录。支持邀请家人加入家庭、绑定儿童手表，以及从「我的」进入账号资料、权益、反馈和测试邀请。家长通过统一用户中心登录。

此 Android 版本暂不提供活动、照片浏览或系统相册分享入口。商店截图和描述须以实际 Android 包为准，不能使用 iOS 活动照片页面冒充 Android 功能。

## 审核说明

- 登录需使用用户中心账号，手机端默认家长身份。
- 主要路径：登录 → 选择或创建家庭 → 添加孩子 → 记录积分或零用钱 → 查看交易记录／审批申请。
- 无广告 SDK；当前 Manifest 仅声明网络状态和联网权限。最终权限清单以签名包解析结果为准。
- 儿童手表为单独应用，家长在本应用内生成限时授权码后完成配对。
- 审核测试账号、可访问的测试家庭、应用截图、分级问卷和数据安全表须在目标商店后台依据真实包与账号完成。不要将真实账号密码写入仓库。

## 提交前验收

1. 从已推送的提交构建并签名 AAB（Google Play）和 APK（国内 Android 商店），记录包名、版本、证书指纹和 SHA-256。
2. 在 Android 真机安装签名 APK，用审核测试账号走通登录、创建家庭、奖励、审批、记录、账号注销入口，并截取真实页面。
3. 验证线上隐私政策为本次版本，含 Android 会话存储、数据删除入口和运营者联系方式。
4. 根据最终包和服务端实际处理情况填写商店数据安全、儿童与家庭、内容分级、隐私政策等表单。
5. 核实目标商店开发者账号、包名占用情况及签名证书；通过商店正式入口上传并读回审核状态。

以上为准备材料，不代表任何应用市场已经受理或上架。
