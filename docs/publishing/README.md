# 家加分三方手表应用市场发布资料

整理日期：2026-08-13

本目录用于承接项目管理“应用上架”统一发布流程。每个平台目录都包含平台材料清单、审核说明、测试报告模板和必须由发布主体提供的项目。

## 平台资料包

| 平台 | 目录 | 当前自动化判断 |
| --- | --- | --- |
| 小天才手表应用市场 | `xiaotiancai/` | 邮件/人工提审为主，需生成提审邮件和附件包 |
| 小米手表应用市场 | `xiaomi/` | 开发者平台网页提审为主，需浏览器自动化上传材料；短信验证码仍需人工输入 |
| 华为 AppGallery Connect | `huawei/` | 若使用 APK/Android 路径，可优先接入 AppGallery Connect API；HarmonyOS 原生手表需另立工程 |

## 统一项目管理要求

项目管理的“应用上架”不能只登记状态，需要能管理完整外部发布包：

- 从项目平台账号读取开发者控制台、联系人手机号/邮箱、测试账号、平台密钥和上架参数。
- 从发布包读取 APK、图标、截图、隐私政策、用户协议、软著、备案、测试报告和审核说明。
- 按平台规则校验材料是否齐全、尺寸是否正确、版本号是否递增、包名是否一致。
- 支持把材料上传到外部平台，生成送审记录，回写外部审核状态。
- 对不能自动化的环节保留人工输入点，例如短信验证码、平台人工沟通、盖章文件、真机截图确认。

详细工具缺口见 `marketplace-release-tooling.md`。
