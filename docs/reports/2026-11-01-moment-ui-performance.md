## 真机基线

- iPhone 13 Pro，实际运行 LinkoXMoment 1.2.66(75)，二进制 UUID 与本地正式 dSYM 一致。
- 巴松措活动 11 项媒体；未创建下载请求，在原列表上下滚动。
- Apple Time Profiler 2026-11-01 15:54:56.686 至 15:55:38.056（设备当地时间 UTC+8），有效记录 41.371 秒。
- 3 次主线程 Microhang：284.332、283.782、280.170 毫秒。
- 三个卡顿窗口合计 846 个主线程毫秒采样；748 个毫秒采样经过日期格式化调用，占 88.4%。这是采样占比，不能当作精确耗时比例或帧率。
- 匹配 dSYM 符号定位到 `DearSocialView.allActivities`、`selectedActivity`、`ActivityListDate.value/parse`、排序和照片行渲染。说明不传输也有列表渲染短卡顿，照片数量与重复渲染会放大开销。

## 实现

- 日期解析器复用；记录加载时预解析时间点；照片行直接查找当前活动，避免每行重新排序整个活动列表；日历日期按设备当前时区解释。
- 列表先展示，预览修复和位置补充异步执行；照片按可见行加载，五列网格拆成独立 List 行。
- 图片预览最多四个并发请求，同路径合并，解码图片 NSCache 上限 64 项 / 32 MiB，60 秒过期，退出清理。
- JSON 解析、原件文件复制、缩略图生成、原图最大 2048 像素显示缩放在后台；原文件保持完整。
- 发送与批量下载进度隔离为独立观察对象，最多每秒五次有效刷新，不触发整个活动页面刷新。
- 详情只加载当前页原件、播放器和点评，离开页面释放显示资源；再次进入恢复缓存原件。
