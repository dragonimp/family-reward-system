# Moment Android 界面对齐 iOS

版本：1.0.3 (12)，ARM64 本地验证包；未提交、未推送、未通过 Atlas 发布或商店上架。

## 变更

- 按当前 iOS 四栏导航调整为成长、活动、运动、我的。审批、记录和规则归入成长，显示家庭、孩子余额与守约状态；账户页改为分组设置布局。
- 新增原生活动列表和新增弹窗，活动按日历日期倒序、列表不显示时间点；更多操作放入 ⋯。
- 活动合并照片、日常与打卡，提供动态、紧凑、每行五张网格。紧凑模式信息与操作在右侧，昵称优先，地点名称和海拔独立显示，点评只显示数量。
- 原生照片详情提供左右浏览、缩放、下滑退出和点评；缩略图有界缓存并限流异步请求，切换活动取消过时请求。
- 消息列表和已读处理使用 AgentIdentity.NativeClient NotificationClient，读取正式后端的用户中心配置。
