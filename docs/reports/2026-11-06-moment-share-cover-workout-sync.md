# 活动邀请页、运动地图与账号同步

## 已交付行为

公开活动介绍改为封面邀请卡片：App Logo、活动名称、时间、简介、主按钮及安装/网页入口。活动默认取最早一张已有服务端小预览的未撤销照片；没有可用照片时显示默认封面。封面不返回原图或完整媒体目录，跨租户读取仍受路径绑定约束。替换或撤销照片后不再返回旧预览。Logo、默认封面作为 API 内嵌资源发布，避免依赖另一个静态站点版本。

页面包含微信图标/封面元信息、favicon、未安装提示、系统浏览器指引及 App Store 正式入口。主按钮顺序保持“打开 App → 安装测试版 → 继续网页版”，没有旧版提示。Apple Lookup 独立核验：`net.impx.happylife` 对应 6828813434，美区/港区正式版 1.2.59，中国大陆区无结果；页面说明地区限制。未提交新的 App Store 审核或改变正式版。

运动页去掉顶部介绍，增加数据/地图切换。地图模式下开始运动才请求定位，支持锁屏定位；暂停/结束停止定位。轨迹按暂停、重启及长时间定位中断分段，过滤过旧/低精度/异常定位，记录数有限额。历史记录可查看轨迹。账号变化立即停止定位。

已完成记录与轨迹通过用户中心认证的 `/api/exercise/records` 上传/下载。服务器从认证主体确定所有者，不接受客户端指定账号。记录 UUID 类型化，上传可幂等重试；同 ID 不同内容拒绝覆盖；删除保留墓碑，防止离线设备重新上传已删除记录。客户端保留本机数据、同步状态和删除待办，进入页面、回到前台、完成或删除时同步，也可手动重试。进行中的计时不跨设备接续。

服务器正常用户内容写入 `Exercise:DataDirectory`，默认服务账号 LocalApplicationData 下的 `LinkoMoment/exercise-records`，位于发布目录之外；私有账号目录、原子文件发布及进程间锁保护写入。没有启动建表、历史回填或生产照片数据修复。
