# Moment 直接拍摄与共享

## 实现

- 活动详情的共同相册增加「拍照」「录制视频」。使用系统相机全屏呈现，支持系统的重拍、确认和取消；录像最长 3 分钟。
- 按需申请相机权限，录像另申请麦克风权限；保存仅申请相册添加权限，不要求读取整个相册。未授权或无相机的设备显示说明及设置入口，仍可使用已有相册选择器。
- 拍摄前固定目标活动、地点和登录会话；拍摄确认后先保存到系统相册，再调用既有 `DearPhotoSource` 分享到目标活动。传输仍复用 Linko Connect SDK，推送仍复用用户中心 SDK。
- 拍摄视频在系统回调内复制到 App 临时目录，避免相机释放临时文件后丢失；照片转换为 JPEG。保存或共享失败时保留本次文件并提供重试、另存和移除入口；成功共享后清理临时文件。保存已成功的重试跳过相册写入，避免重复保存；关闭 App 后可从系统相册重新选择已经保存的内容。
- 登录会话变化时停止共享，避免将拍摄结果发布到另一账号。活动共享仍执行原有成员权限和文件大小校验。

仅修改 iOS 客户端，无服务端或数据迁移。本次发布源码 `5ba30957187eedb30c33daca361e5eed5bbc81ea`，已推送正式 GitHub `main`。
