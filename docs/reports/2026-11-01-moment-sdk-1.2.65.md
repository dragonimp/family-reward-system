## 合并内容

- 活动列表右侧新增按钮打开表单，活动日期倒序、列表只显示日期。
- 照片卡片优先显示用户中心昵称；保留批量删除本人分享、上传者直接播放本机视频及活动链接分享。
- 生活分享与打卡合并到按时间排序的动态；重新组织照片、动态、位置与成员布局。时间点按设备时区转换并标注当地时间，纯日期保持日历日期语义。
- 原文件仅经 Linko Connect 公共 SDK 的可靠有序 DataChannel 传输；含分块、SHA256、前缀续传、持久化确认、取消和短期授权续接。业务自有文件 WebSocket 中转已移除。
- 系统推送与令牌登记只复用用户中心 SDK。Linko 的旧 APNs Worker 已移除；用户中心按各应用 Bundle ID 调用 APNs。下载请求有站内记录，系统通知点击后读取当前账号有权访问的请求。原文件在共享设备上，传输需要保持应用打开。
