# 家加分手表端使用手册

> 面向孩子与家长的家庭奖励助手。孩子在手表上查看进步、主动申请奖励；家长在家长端设定规则并确认奖励。

## 这是什么

家加分手表端是家加分的儿童侧入口，帮助孩子把每天的小进步看得见、说得清。它适合用于完成作业、整理物品、阅读、按时吃饭等家庭日常约定。

手表端不替代家长管理：孩子可以查看自己的积分和申请奖励，家长负责添加孩子、约定规则、确认奖励和管理设备。

## 开始前，家长需要准备什么

1. 在家长端登录家加分，并添加或选择需要使用手表的孩子。
2. 与孩子一起约定可获得奖励的日常行为，例如“按时完成作业”“整理书桌”。
3. 在孩子管理中生成一次性儿童认证码。
4. 把认证码提供给孩子，在手表端完成首次绑定。

> 认证码用于首次确认这只手表属于哪位孩子。请由家长在安全场景下提供，不要转发给其他人。

## 孩子如何使用手表端

### 1. 首次绑定手表

1. 打开“家加分”手表端。
2. 在“设备绑定”页输入家长提供的儿童认证码。
3. 点击“绑定”。
4. 绑定成功后会进入积分首页。

如果提示认证码无效或已过期，请让家长重新生成新的认证码后再试。

### 2. 查看自己的积分

首页会清晰展示三个信息：

- **积分**：当前获得的积分总数，是首页最主要的信息。
- **现金**：家庭规则中记录的现金积累。
- **物品**：家庭奖励中记录的物品数量。

点击手表右侧的“菜单”，可进入积分详情、奖励申请、好友、排行榜、表盘设置和设备信息。

### 3. 申请奖励

当完成了与家长约定的事项后：

1. 打开“菜单”，选择“积分申请”。
2. 选择对应的奖励规则；也可以补充简短的申请事项，例如“我整理好了书桌”。
3. 如需语音输入，主动点击麦克风按钮后说出事项；也可以直接文字输入。
4. 点击“提交”。

提交后，申请会显示为“待审核”。这表示申请已提交给家长确认，积分不会立即变化。

### 4. 查看家长确认结果

打开“积分详情”，可查看最近申请：

- **待审核**：家长尚未确认，请耐心等待。
- **已通过**：家长已确认，相关奖励会体现在积分或奖励记录中。

如果家长暂未通过，建议和家长沟通完成情况，按家庭约定继续努力。

### 5. 好友与排行榜

在家长允许的范围内，孩子可以使用好友码添加好友，并查看好友积分榜。排行榜的目的不是攀比，而是互相鼓励、一起坚持好习惯。

请只添加家长认可的朋友；不要向陌生人索要或提供好友码。

### 6. 设置喜欢的表盘

在“表盘设置”中，孩子可以选择喜欢的主题，例如我的世界、星光梦可、恐龙乐园、彩虹糖果或宇宙探险。更换表盘只改变显示风格，不会影响积分和申请记录。

## 家长如何配合

建议家长把家加分当作亲子沟通工具，而不仅是记分工具：

- 规则要具体、可完成，例如“阅读 20 分钟”比“好好学习”更容易理解。
- 及时确认孩子的申请，并说明通过或需要改进的原因。
- 关注孩子的持续进步，不只关注积分总数。
- 奖励可以是共同活动、阅读时间或小目标，不必总是物质奖励。

## 更换或解绑手表

同一孩子同一时间只使用一只有效手表。

如果需要更换设备：

1. 家长先在家长端解除旧手表的绑定，或生成解绑认证码。
2. 孩子在旧手表的“设备绑定”页按提示完成解绑（如仍可使用）。
3. 家长为新手表生成新的儿童认证码。
4. 孩子在新手表上按“首次绑定手表”的步骤重新绑定。

这样可以避免旧设备继续显示孩子的奖励信息。

## 常见问题

### 为什么我提交后积分没有马上增加？

手表端提交的是奖励申请。家长确认后，结果才会更新到孩子的积分和奖励记录中。

### 为什么手表提示重新绑定？

可能是家长已经解绑了旧设备、设备被更换，或此前的认证已失效。请联系家长重新生成儿童认证码。

### 不允许语音输入还能使用吗？

可以。语音输入是可选功能，不开启也可以通过文字填写申请事项。

### 手表端有没有广告、付费或陌生人社交？

没有。家加分手表端专注家庭奖励与习惯培养，不提供广告、儿童侧付费或公开陌生人社交功能。

## 让家加分真正发挥作用

家加分最重要的不是“得多少分”，而是让孩子知道：每一次认真完成、主动承担和持续坚持，都会被家人看见并得到回应。
