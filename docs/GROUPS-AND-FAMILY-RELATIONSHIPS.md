# 群组与真实家庭关系

- 「群组」是为共同记录孩子成长、积分和规则而建立的虚拟小组。加入群组不证明存在亲属关系；旧 `family_groups` 数据和 API 路径保持兼容。
- 「我的关系」管理真实家庭成员、族谱和家人邀请。家庭成员是当前家长账号下的业务资料，族谱人物属于具体族谱；两者不会按姓名自动合并。
- 家长可在已加入的族谱中，把自己的家庭成员明确关联到某一人物。一个家庭成员可关联多个族谱，每个族谱最多关联该家庭成员一次；同一族谱人物在同一家庭资料下只能关联一位成员。本人资料只能关联已绑定当前账号的族谱人物。
- 解除关联只删除映射，不删除家庭成员、族谱人物或亲属关系。族谱里的父母、子女和配偶边仍是血缘与婚姻关系的权威记录，家庭角色只用于当前家长视角的展示，不自动生成族谱关系。
- 关联 API 只向当前家庭资料的所有者返回映射，并要求该用户仍是目标族谱成员。管理员之外的族谱成员可为自己的家庭资料建立映射，但不能因此修改族谱人物或关系。

数据库变更为独立的一次性迁移 `scripts/migrations/20261010-household-genealogy-links-v1.sql`。部署前备份，使用 `scripts/run-db-migrations.sh` 执行并核对内容校验与执行记录；应用启动不运行迁移。
