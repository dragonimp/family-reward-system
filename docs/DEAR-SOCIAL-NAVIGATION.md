# Linko Dear 活动与空间

- 生活空间用于归拢一组活动。切换空间只改变活动列表，不代表真实家庭、族谱或好友关系。
- 活动属于一个空间；活动邀请、成员、照片和日常均以该活动为范围。收到邀请后须确认加入。
- 网页活动列表位于 `/dear`，详情位于 `/dear/spaces/:spaceId/activities/:activityId`；详情地址可直接打开，并由现有服务端权限检查。
- iOS“活动”页显示空间和活动列表；点选活动进入详情，返回可换空间。创建活动后直接进入新活动详情。
- 好友关系跨空间存在，需要双方确认。在活动详情可以对活动成员申请好友；全局好友和申请放在列表页的折叠入口。
