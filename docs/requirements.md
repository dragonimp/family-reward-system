# 家加分需求清单

## 需求基线

完整功能点及验收口径统一维护在 [FEATURE-CATALOG.md](FEATURE-CATALOG.md)。该目录由 `family-reward-REQ-024` 重新梳理，覆盖家长 Web、儿童手表、API、数据模型、智能体和 MCP，并明确角色、权限和外部发布边界。

## 产品能力分组

- 登录、身份与账户：统一登录、家长/孩子应用身份、受保护路由和账号菜单。
- 家庭协作：家庭组、8 位邀请码、入组同步孩子、孩子成员管理和家庭访问隔离。
- 孩子档案与账户：全局孩子档案、家长归属、跨家庭成员关系以及共享积分/现金/物品账户。
- 奖励与规则：三类账户正负调整、规则快捷记账、语音解析、批量交易和删除回滚。
- 记录与统计：家庭仪表盘、多条件交易查询、CSV 导出和统计报表。
- 儿童手表：一次性绑定、积分查询、规则与申请、设备管理、解绑码、跨机型适配和上架准备。
- 系统与集成：语音/智能体配置、智能体调试、MCP JSON-RPC 工具服务。
- 安全与运维：PostgreSQL 持久化、事务一致性、凭据保护、健康检查和自动化回归入口。

## 当前边界

- 真实的小天才、小米、华为商店上架仍依赖发布主体账号、签名证书、合规资料和目标真机，工程准备完成不等于审核完成。
- 语音识别依赖浏览器 Web Speech API，需要 HTTPS 和兼容浏览器。
- `server/` 与 `backend/` 是历史 Python 实现，不属于当前 ASP.NET Core 产品基线。
- Atlas MCP 当前不可用，REQ-024 和 TASK-038 的远端状态、测试和证据仍待连接恢复后同步。
