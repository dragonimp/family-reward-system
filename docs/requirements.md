# 家加分需求清单

## 已确认需求
- 家庭成员/孩子积分、现金、物品管理。
- 规则与红线管理（支持正向与负向）。
- 交易记录与统计报表。
- 系统可视化配置（含导航与页面可达性）。

## 新增补充需求
- ✅ 支持语音输入进行配置：在“系统配置”页，对可输入配置项提供麦克风录入能力。
- ✅ 支持调用智能体服务：通过后端配置的服务地址统一转发，前端提供测试入口并展示返回结果。
- ✅ REQ-016 手表查询界面跨机型适配：禁止页面和内容面板滚动，按动态视口、横竖屏、安全区与实际内容尺寸主动适配。
- 📝 REQ-030 手表端菜单重构：需求分析已完成，实施待排期。右侧固定为单一菜单入口，菜单页平铺积分申请/详情、添加好友/排行榜、表盘设置/设备绑定六项并配图标；积分申请增加语音转文字和带图标常用项。详细口径见 [REQ-030-ANALYSIS.md](REQ-030-ANALYSIS.md)。

## 说明
- 语音识别使用浏览器能力，需 HTTPS/兼容浏览器环境。
- 智能体服务密钥按后端配置保存，前端仅用于触发与回显。
- REQ-030 的语音能力必须保留键盘输入降级，并在目标手表 WebView 真机验证浏览器识别和麦克风权限链路。
